#   - adafruit_hid, board, digitalio, usb_hid -- CircuitPython firmware modules

# Note: pyautogui installs fine but `import pyautogui` RAISES KeyError: 'DISPLAY'

# such as a Repl, any file importing it crashes on the import line, not later.
# pygame degrades gracefully instead: with no display, SDL falls back to its
# "offscreen" video driver, so import and set_mode() both succeed and nothing
# crashes -- you simply see no window.
#
# Note: PyPDF2 is deprecated upstream in favour of pypdf, but the code here does
# `import PyPDF2`. Switching requires editing those files, so it stays as-is.
